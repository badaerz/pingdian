# golden set 人工审定清单

> 由 `node scripts/golden-review.mjs` 生成。推理由 AI 起草，**必须人审定**才计分。

## 怎么用

1. 逐条看每个 case 下面的结论，只判断一件事：**这条结论，真的是这段文本里的问题吗？**
2. 在每条的 `[ ]` 里打 `x` 表示「成立」，打 `/` 表示「不成立」；不改动的保持 `[ ]`
3. 判完整行 case 后，在 case 末尾的 `审定人：` 后面写你的名字
4. 存盘，然后跑 `node scripts/golden-review.mjs --apply`

**只标 `x` 的会被写进 JSON。** 标 `/` 或留空的，该条不会被记为审定通过，
整个 case 也不会被标为已审定——宁可留白，不要凑数。

## GC_037 · 湖心亭看雪·一痕与一粒

- 来源：`湖心亭看雪` · 张岱《湖心亭看雪》全文（段 1–4，自“崇祯五年十二月”至“更有痴似相公者”） · 体裁 `lyric` · narrative

- [ ] **1.** 雪景不靠形容词，靠量词把空间压成尺寸：「长堤一痕，湖心亭一点，与余舟一芥，舟中人两三粒」——痕、点、芥、粒四个量词各自对应一种实物的轮廓，读者据此能排出远近大小，这是具象细节的样板写法

  - 依据判据：`V1` · 性质：`positive` · 严重度：medium

  - 关键词：第一人称 / 问其姓氏 / 不越界
- [ ] **3.** 结尾用舟子一句话收束：「莫说相公痴，更有痴似相公者」。前面写“独往”的孤，收在“更有痴似”的不孤，一句话把整篇的自况翻了个面，收束句同时承担了转意
  - 依据判据：`S1` · 性质：`positive` · 严重度：medium
  - 锚点（须逐字在原文）：`更有痴似相公者`
  - 关键词：收束 / 翻转 / 自况

**模型若断言以下内容，即为编造（用于测误报）：**

彷徨在悠长，悠长
