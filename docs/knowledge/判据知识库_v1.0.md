# 文学诊断判据知识库 v1.0

> 合并自四轮产出，18 条判据，六维 × 3 条。条目内容取自各条最新版本，仅按本文件 §1.1 与 §4 的规格做了指定合并修订。

## 0. 这份文件是什么 / 怎么用

**给谁看**：产品（定义能力边界）、开发（实现 metric）、评测（写 golden set 与判分）、以及被追问时的答辩者。判据本身是给人看的中文规则，不是给模型看的提示词。

**判据怎么被引用**：诊断输出的 `assessment` 字段必须引用条目 `id`（如 `P3`），且引用的条目必须在本文档中存在；模型不得自造编号，也不得引用该文本不适用（见各条 `notApplicable`）的判据。引用是本项目「结论可溯源」的落点——没有判据编号的意见，在代码层丢弃。

**改动走什么流程**：见配套《判据库维护手册》§2.3。一句话：改 `metric` 必须重跑 golden set，改 `statement` 必须同步 PRD 与评测口径，任一改动都要在 §6 记录版本与理由。

**两条贯穿全文件的边界**（不是免责声明，是设计约束）：

1. **P1 与 P3 的分工**：P1 管任意句（只堆抽象评价词而无具体名词），P3 只管关键场景（转折处有没有一个可指认的细节）。**关键场景内的空转评价句归 P3，不归 P1**；两者同时命中时只报 P3（更具体的那条）。完整分工见 §4。

2. **pending 条目（C1、D2）不得被当成判定用**：它们的阈值依赖尚未建立的参照带，当前只采集数值、不产出「达标 / 不达标」。任何把二者当二值判据用的实现都是错的。

## 1. 字段规格

### 1.1 text 字段分级

| 级别 | 字数上限 | 适用条目与理由 |
|---|---|---|
| 常规条目 | 15–60 字 | P1 P2 P3 · D2 · V1 V2 V3 · S1 S2 S3 · C1 C2 C3 |
| D1 / D3 | ≤ 450 字 | 判据自身要求连续 200 字（D1）或单段 > 400 字（D3），60 字上限下结构上无法回代；**这是正式规格变更，不是笔误** |
| M1 / M2 | 80–120 字 | 需要两段呈现才能演示「跨段」，按 R3 方案 b 执行，note 开头注明「压缩呈现」 |

> **「字」的口径**：本文件一律指**汉字，不含标点与空格**（与 D1 / D3 的 note 口径一致）。四轮产出里多数条目实际按「字符含标点」计数，两者差 10–20%。按汉字口径复核，原有 6 处例句低于各自下限；其中 4 处（M1 正/反例、M2 正/反例）已在 v1.0 修订中补足并同步修正分段方式，剩余 2 处（S2 反例2、C2 反例2）登记在 §5。

### 1.2 其余 11 个字段的语义

| 字段 | 语义 |
|---|---|
| `id` | 条目编号，维度首字母 + 序号（P / D / M / V / S / C）。检索与引用都用它，**必须是稳定标识**，改编号等于换一条判据。 |
| `dimension` | 所属维度，取值限于本文件定义的六个维度名，不得自由书写。 |
| `statement` | 判据的一句话命题，由产品定义侧给出、**已通过验收，一字不改**。它是给人看的入口，也是与 PRD 的对应锚点。 |
| `checkable` | 可二值判定的操作描述：对什么对象、取什么口径、判定结果是什么。凡是写「有无」「是否」「不出现」的，必须穷举形态或给计数口径。 |
| `metric` | 算出 checkable 的具体计算规则：单位、窗口、词表、边界情形、排除项。**这是可复算性的全部来源**，改它等于换一条判据的算法。 |
| `authority` | 出处数组，每项含 claim / source / url。学术或行业依据只能来自真实存在且可打开的来源；本项目约定：不确定宁可不写。 |
| `typicalTrue` | 正例数组，每项含 text / note。note 必须写「回代过程」——按 metric 算出来是多少、为什么判定成立，供验收方手工复算。 |
| `typicalFalse` | 反例数组，每项含 text / note。要求同正例。反例不能是 commonFalsePositive 里声明「不该报」的类型（R2 互斥）。 |
| `commonFalsePositive` | 常见误报清单：同样长得像命中、但**不应报**的情形。它的作用是在评测里把「误报」和「真阳性」分开。 |
| `notApplicable` | 不适用条件，必须给**可识别的特征**，不能只写概念名（如不能只写「抒情段」，要写怎么认出抒情段）。 |
| `confidence` | 置信状态：`draft`（可二值判定，待评测复核）、`draft-pending-threshold`（阈值未定，当前只采集不判定）。不得为后一种自拟阈值。 |

## 2. 六个维度

维度只有六个，选入标准是四条同时成立：有公认出处 / 可量化 / AI 可实现 / 符合「防幻觉文学诊断」的产品定位。为什么不开第七维，见《维护手册》§2.2 的否决记录。

### 2.1 具体性与感官

**定义**：文本是否把抽象判断换成可被指认的具体细节（物件、动作、声音、触感）。抽象评价词只给结论，具体细节给证据；读者能不能「看见」，就是这一维要测的东西。三条判据分工是范围递进：P1 管任意句（只堆评价词而无实体），P3 管关键场景（转折处有没有一个能单独摘出来的细节），P2 管全篇感官通道的覆盖面。

**权威出处**：

- Show, Don't Tell（De Gruyter 专著章节）（https://www.degruyterbrill.com/de/document/doi/10.1515/9780773558502-006/html）
- 6+1 Traits of Writing（Ruth Culham, Scholastic）（https://www.scholastic.com/teachers/teaching-tools/articles/6-1-traits-of-writing--the-complete-guide-for-the-primary-grades.html）
- 《福建省初中语文学科教学与考试指导意见》（含依据课标编写的写作要求转述）（https://sz.xmnn.cn/Uploads/Editor/2018-10-27/5bd38d0f74a10.pdf）

**判据列表**：

- `P1` 有没有句子只堆抽象评价词而无具体名词
- `P2` 全篇感官通道覆盖 ≥ 2 类
- `P3` 关键场景（转折处）有没有一个可指认的具象细节（一个物件、一个动作或一个声音）

**常见误报**：

- 把概括性过渡句判成空转——过渡句本身不承担具体化功能。（`P1`）

**不适用**：

- 议论段、说明段（识别方式：以判断句或说明句为主、无时间推进、出现“因此 / 可见 / 所谓 / 指的是”等论证或释义标记，且全段无连续两个以上可观察动作）。（`P1`）
- 议论段、说明段。（`P3`）

### 2.2 信息密度与节奏

**定义**：单位篇幅里新信息（事件、具体名词、新事实）的多少，以及密度在段落层面是否与段落功能匹配。密度为零的滑窗是拖沓的硬证据，长短段的排布是节奏。D1 看滑窗（连续 200 字零信息），D3 看单段（超 400 字却几乎没有事件），D2 看段际差（暂不判定）。

**权威出处**：

- Beats Per Minute, Cognitive Load, Chunking Limits, and Cross-Cultural Narrative Dynamics（Zenodo 预印本 v8, DOI 10.5281/zenodo.19064445）（https://zenodo.org/records/19064445）

**判据列表**：

- `D1` 有没有连续 ≥ 200 字不产生任何新信息（纯复述、形容词堆叠、同义反复）
- `D2` 密度最高段与最低段的差值是否超出参照带上界
- `D3` 有没有单段 > 400 字却只有 0–1 个事件

**常见误报**：

- 把抒情段的低密度判成拖沓。（`D1`）

**不适用**：

- 全文字数 < 200 字的文本（识别方式：按汉字计数不含标点，不足 200 字时 200 字窗口无法滑出，本维度不判定）；建场段、抒情段按功能条件化判断——各功能各看各的密度区间，不套全局阈值。（`D1`）
- 段落数 < 2 的文本（识别方式：按换行或空行统计段落，只有 1 段时“最高段 / 最低段”无对象，本维度不判定）；建场段、抒情段按功能条件化判断——各功能各看各的密度区间，不套全局阈值。（`D2`）
- 全文字数 ≤ 400 字的文本（识别方式：按汉字计数，全文不超过 400 字时不存在“单段 > 400 字”的可能，本维度不判定）；建场段、抒情段按功能条件化判断——各功能各看各的密度区间，不套全局阈值。（`D3`）

### 2.3 意象复现

**定义**：同一个具象名词短语反复出现、并在复现中变形，构成文本内部的呼应结构。三步是连续动作，不是三个并列指标：先抽出来（M1 抽取层）→ 再看是否跨段（M2 结构层）→ 最后看复现时含义有没有跟着处境推进（M3 语义层）。M1 通过不等于意象成立。

**权威出处**：

- Motif - Definition and Examples（Poem Analysis）（https://poemanalysis.com/literary-device/motif/）

**判据列表**：

- `M1` 抽出全篇具象名词短语，出现 ≥ 2 次者为候选意象
- `M2` 候选里有没有至少一个跨段复现（跨越至少 2 个段落）
- `M3` 候选意象中，至少一处复现须满足：形态发生了变化，且该变化指向人物处境或主题的变化。形态变化指：词形变化 / 修饰语变化 / 功能位置变化。

**常见误报**：

- 功能性重复判成意象（如「门」反复出现只是场景切换，不承担含义推进）。（`M1`）
- 代词当意象（「他」「这」高频出现但无所指实体）。（`M1`）
- 单次出现判成伏笔（仅出现一次的物件不属于本维度可判定范围）。（`M1`）
- 功能性重复判成意象（如“门”反复出现只是场景切换，不承担含义推进）（`M3`）
- 代词当意象（“他”“这”高频出现但无所指实体）（`M3`）
- 单次出现判成伏笔（仅出现一次的物件不属于本维度可判定范围）（`M3`）

**不适用**：

- 段落数 < 2 的文本（识别方式：按换行或空行统计段落，全文只有 1 段时不存在“复现”的空间，本维度不判定）。（`M1`）
- 段落数 < 2 的文本（识别方式：按换行或空行统计段落，全文只有 1 段时跨段复现在物理上不可能，本维度不判定）。（`M2`）
- 段落数 < 2 的文本。（`M3`）

### 2.4 视角一致性

**定义**：叙述者有没有越出自己的位置——人称无故切换、进入不该进入的人物的内心、让人物使用无人告知的信息。前提是先判定这篇是不是有限视角；全知体（零聚焦）不适用本条三条判据，这一点是硬前置，不是免责条款。

**权威出处**：

- ConStory-Bench: Lost in Stories — Consistency Bugs in Long Story Generation by LLMs（ACL 2026；GitHub README）（https://raw.githubusercontent.com/Picrew/ConStory-Bench/main/README.md）

**判据列表**：

- `V1` 叙述人称不无故切换
- `V2` 出现“他想 / 她感到 / 他觉得”时，被写的是不是本段视角人物
- `V3` 有没有“知道无人告知的信息”

**常见误报**：

- 把全知体写成“视角混乱”。判定前提是全篇先判是否有限视角。（`V1`）

**不适用**：

- 全知体（零聚焦）文本（识别方式：叙述者能自由进入两个以上角色的内心——出现 ≥ 2 个角色各自的“他想 / 她感到”类心理描写，且无「他不知道的是」这类宣告把它们切成视角切换；或出现「与此同时」「另一边」式的全知调度。满足任一即判全知体，V1–V3 全部不适用）。（`V1`）
- 全知体（零聚焦）文本（识别方式同 V1：出现 ≥ 2 个角色各自的心理描写且无宣告切分，或出现「与此同时」式全知调度）；另：该段 (a)(b)(c) 三项分指不同人且无 (a)+(b) 交集，或段内无任何位置 / 感知 / 动作链证据（纯抒情句、纯对话段）时，该段不适用。（`V2`）
- 全知体（零聚焦）文本（识别方式同 V1：出现 ≥ 2 个角色各自的心理描写且无宣告切分，或出现「与此同时」式全知调度）。（`V3`）

### 2.5 结构组织

**定义**：每一段在整体里承担什么功能（建场 / 推进 / 转折 / 抒情评述 / 收束），有没有段落归不进去，收尾有没有真正收住。S2 判段落能否归类，S3 判全文有没有转折，S1 判结尾是否完成收束——三者是「局部—全局—结尾」三个位置。

**权威出处**：

- 6+1 Traits of Writing（Ruth Culham, Scholastic）（https://www.scholastic.com/teachers/teaching-tools/articles/6-1-traits-of-writing--the-complete-guide-for-the-primary-grades.html）
- 6+1 Traits 组织维度改编量表（NWREL / BC Performance Standards）（http://blogs.sd41.bc.ca/learningtech/files/2010/11/6traits-writing.pdf）
- 《福建省初中语文学科教学与考试指导意见》（含依据课标编写的写作要求转述）（https://sz.xmnn.cn/Uploads/Editor/2018-10-27/5bd38d0f74a10.pdf）

**判据列表**：

- `S1` 最后一段有没有收束功能（不再引入新情节、回应开头或给出结局）
- `S2` 每个段落能否归入五类功能之一，归不进去的段落 ≤ 1 个
- `S3` 全文有没有至少一个明确转折（人物处境或已知信息发生变化）

**常见误报**：

- 把“开篇不进入冲突”判成结构缺陷——若首段功能明确为建场且完成了建场，不报。（`S1`）

**不适用**：

- 段落数 < 3 的文本。（`S1`）
- 段落数 < 3 的文本（识别方式：按换行或空行统计段落，少于 3 段则开头—展开—收束三段式在物理上不可分，本维度不判定）。（`S2`）
- 段落数 < 3 的文本（识别方式：按换行或空行统计段落，少于 3 段时不存在“变化前—变化后”的可定位区间，本维度不判定）。（`S3`）

### 2.6 连贯衔接

**定义**：相邻句之间有没有可命名的关系（因果 / 时间 / 转折 / 递进 / 并列 / 举例），指代有没有落点，主题有没有断层。C1 判关系占比（阈值未定，只采集），C2 判指代是否悬空，C3 判是否存在语义断层。

**权威出处**：

- How to teach paragraph-level cohesion（IELTS 官方教学文章）（https://www.ielts.org/news-and-insights/how-to-teach-paragraph-level-cohesion）

**判据列表**：

- `C1` 相邻句对中，能说出关系（因果 / 时间 / 转折 / 递进 / 并列 / 举例）的占比达标
- `C2` 每个指代词（他、她、它、这、那、该）都有明确先行词，无悬空指代
- `C3` 无语义断层：相邻两句主题词完全不重叠且无连接词

**常见误报**：

- 把刻意的短句断裂（人物震惊、动作急促）判成断层——若前后段有情绪标记，不报。（`C1`）

**不适用**：

- 意识流、诗歌体（本期限定叙事，直接排除）；（识别方式：以分行断句为主且无施事主体的连续意象并置，或整段无标点句读，即判为不适用）。（`C1`）

## 4. 跨条目分工

合并成一本之后才出现的风险：两条判据在同一段文本上都可能命中。逐对写死边界，避免同一处被报两次、或两边互相推。

| 对 | 边界 | 双报时只报 |
|---|---|---|
| P1 ↔ P3 | P3 只管关键场景（转折处）里的具象细节；P1 管任意句的抽象词堆叠。关键场景内的空转评价句归 P3。 | **P3**（更具体） |
| M1 ↔ M2 ↔ M3 | 三层递进：M1 抽取层（有没有候选）、M2 结构层（有没有跨段复现）、M3 语义层（复现时含义有没有推进）。M1 通过 ≠ 意象成立。 | **最具体的未过层**（M3 先于 M2 先于 M1） |
| V2 ↔ V3 | V2 罚叙述者（进入非视角人物的内心），V3 罚人物（使用无人告知的信息）。两者主体不同。 | **V3**（信息违规更硬） |
| D1 ↔ D3 | D1 是 200 字滑窗级，D3 是段落级（> 400 字且事件 ≤ 1）。同一段落可同时命中。 | **D3**，D1 记「同段已覆盖」 |

## 5. 已知局限

这些是诚实记录，不是待修 bug。删掉它们等于隐瞒边界。

| 条目 | 局限 | 为什么现在不修 |
|---|---|---|
| `D1` | **纯心理推进段必然被判零信息窗**。情绪转折在人看来是新信息，但三类新信息单元（新事件 / 新具体名词 / 新事实）都不含「情绪」。 | 加「情绪」类单元需要情绪标注表，会引入新的不可复算面；目前靠 `notApplicable` 的「抒情段功能条件化」兜。 |
| `P2` | **纯视觉白描只有 1 类通道，会被判不通过**。通篇只写色彩的景物段是文学上成立的写法。 | 阈值「≥ 2 类」由判据原文写死，改它等于改 statement 语义，需产品侧决定。 |
| `M1` | **只出现 1 次的伏笔无法被本维覆盖**。M1 的门槛是「出现 ≥ 2 次」，单次埋设的细节不进候选，因此这类伏笔在六维里无归属。 | 单次伏笔的判定要模型做因果推理，正是本项目要避免的形态；宁可漏，不可猜。 |
