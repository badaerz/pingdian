# Story Forge React + GSAP 主页视觉重构设计

## 目标

以用户提供的新 Logo 为视觉基准，在现有 Next.js 16、React 19 项目中重构完整主页。主页需要体现文学、科技与教育的融合气质，同时保留当前可运行的产品入口、答辩案例与功能边界。

本次设计采用品牌核心、Awwwards 编辑式叙事和真实产品入口相结合的方案。主页使用奶油白、炭黑与熔炉橙作为主色，深色知识图谱章节形成视觉节奏转折。内部工作区不跟随主页重构，仅修复用户截图中明确标注的创作台标题遮挡问题。

## 技术与范围

- 保留 Next.js App Router、React、现有路由和产品数据。
- 使用现有 `gsap` 与 `ScrollTrigger` 实现首屏入场、章节渐进出现、流程线绘制和轻量视差。
- 不执行参考文本中的 Vue 迁移、单页路由替换或额外依赖安装指令。
- 新 Logo 复制到 `public/brand`，使用带日期或内容标识的新文件名避免浏览器缓存旧资产。
- 首页主要修改 `marketing-home.tsx`、`marketing.css` 和滚动动画组件；创作台仅修改与标题遮挡直接相关的布局样式。
- 保留创作台、文学诊断、知识图谱、写作训练、IP 实验场和答辩案例的真实链接。

## 视觉系统

### 色彩

- 页面底色：奶油白，接近 Logo 背景，但需通过边界、纹理和层次避免整页单色化。
- 主要文字：炭黑与墨黑。
- 品牌强调：熔炉橙，用于关键节点、进度线、标签和主要按钮。
- 深色章节：近黑背景，以奶油白正文和熔炉橙高亮形成对比。
- 森林绿保留为产品内部工作区颜色，不再作为主页主导色。

### 字体与形态

- 中文展示标题使用现有衬线字体体系，正文沿用可读性更高的无衬线字体。
- 英文标签使用大写和正向字距，不使用负字距。
- 页面区块采用全宽带状或无框布局；只在案例、交互工具和重复项目中使用卡片。
- 不使用渐变球、装饰性圆斑或嵌套卡片。

## 页面结构

### 1. 导航与 Hero

- 导航初始与 Hero 融合，滚动后增加实体背景和细边界。
- 新 Logo 是第一视口的核心视觉，使用完整正方形比例和 `object-fit: contain`，不得裁切文字、英文标识或底部标语。
- Logo 周围使用 React 元素与 SVG 轨道构成缓慢运动的节点系统，呼应 Logo 中的人物、灵感、世界、分析、写作和知识符号。
- 标题、定位文案和两个真实操作入口直接叠加在全幅场景中，不采用左右卡片式 Hero。
- Hero 高度使用响应式约束，并在首屏底部露出下一章节提示。

### 2. 产品理念

- 使用编辑式大字和短句说明产品立场：AI 辅助文学判断，不替作者做最终选择。
- 删除主页文案中“能”字后不必要的逗号。
- 用户确认、本地优先和证据可追溯三项原则以紧凑信息带呈现。

### 3. 核心能力

- 创作、诊断、知识图谱和训练四项能力使用连续信息带，而非普通营销卡片墙。
- 每项能力保留现有名称、功能边界、说明和真实页面链接。
- 滚动进入时编号、细线、标题和说明按短时间差依次出现。

### 4. 创作流程

- 使用五步流程：输入灵感、生成设定、构建蓝图、协作写作、诊断与导出。
- 桌面端为横向流程，移动端切换为纵向流程。
- SVG 进度线随滚动绘制，节点按进度点亮；动画仅使用 transform、opacity 和 SVG stroke 属性。

### 5. 文学知识图谱

- 使用全宽深色章节作为视觉高潮。
- 中心节点为“文学”，外围节点包括作品、作者、主题和技法。
- 节点与路径统一由 SVG 坐标系统绘制，线条准确连接到节点边缘，修复“作品”与连线断开的问题。
- 该图谱是产品能力示意并继续链接到真实知识图谱页面。

### 6. IP 实验场与路线图

- 保留《回响的草场》角色主视觉、现有能力说明和 IP 实验场入口。
- 路线图浅色区域的标题使用炭黑或深墨色，正文使用中灰，保证文字对比清晰。
- P2、P3 标签继续使用熔炉橙，并明确区分可试用能力与规划内容。

### 7. 案例、CTA 与页脚

- 保留两个答辩案例及其现有路由。
- CTA 使用大标题和单一主要行动，避免额外订阅或未实现入口。
- 页脚再次展示完整 Logo，并保留产品入口导航。

## 动效设计

- Hero 加载时 Logo 与标题从轻微缩放和透明状态进入，节点随后分批出现。
- 各章节使用 ScrollTrigger 一次性渐进出现，不在反向滚动时反复闪烁。
- 创作流程线使用滚动进度驱动；Logo 轨道仅做低速循环，不影响阅读。
- `prefers-reduced-motion: reduce` 下关闭循环、视差和滚动绘制，内容保持完整可见。
- 移动端缩短动画距离并取消复杂视差，避免标题、Logo、按钮和导航重叠。

## 截图问题对应修复

1. 创作台标题遮挡：让标题容器允许收缩和省略，操作区保持自身宽度；在工具按钮密集时标题不进入操作区下方。
2. Hero Logo 不完整：替换为用户提供的新 Logo，并以完整比例显示，不使用会裁切资产的固定框或 `object-fit: cover`。
3. “作品”节点未连接：使用同一 SVG 坐标系统绘制节点和路径，路径终点落在节点边缘。
4. 浅底白色标题看不清：路线图标题改为深墨色，并验证对比度和实际截图。
5. 主页标点：删除“能”字后的逗号，其他文案不做无关改写。

## 测试与验收

- 组件测试验证新 Logo 资产、主要标题、真实入口和流程节点存在。
- 为主页标点添加回归断言，防止“能，”重新出现。
- 浏览器在桌面、平板和移动端检查 Hero Logo 完整度、标题不重叠、无横向溢出和下一章节可见性。
- 浏览器检查知识图谱“作品”节点与路径实际相接。
- 浏览器检查 IP 路线图标题与浅色背景之间的可读对比。
- 浏览器检查创作台标题在工具栏完整显示或合理省略，不被按钮覆盖。
- 运行相关 Vitest、TypeScript 检查、生产构建和针对性 Playwright 测试。

## 非目标

- 不迁移到 Vue。
- 不改变内部工作区的信息架构或业务流程。
- 不新增未实现的订阅、社区、机构协作或视频导出功能。
- 不修改 AI 确认机制、持久化、数据模型或 API 行为。
- 不重写与主页视觉重构无关的文案、测试或组件。
