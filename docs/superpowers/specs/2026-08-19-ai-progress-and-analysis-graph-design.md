# AI 生成进度与人物图谱稳定性设计

## 目标

为所有现有 AI 入口提供一致、可访问的阶段式进度反馈，并修复文学诊断中人物关系列表切换导致的 `removeChild` 运行时异常。现有 AI 请求、候选确认、正文保护和云端记录逻辑保持不变。

## 交互设计

AI 请求开始后显示四个阶段：准备上下文、检索资料、生成内容、校验整理。进度在等待期间平滑推进但不超过 92%，只有请求成功并通过前端结构校验后才显示 100%。这是一种等待阶段反馈，不声称服务端返回了精确模型进度。

进度组件覆盖灵感、人物、世界观、蓝图、续写、改写、文学诊断、文本解释、训练提交和再次评价。组件使用 `progressbar` 语义和 `aria-live` 文本，并在用户偏好减少动效时关闭非必要动画。

## 图谱修复

Cytoscape 画布由第三方库管理内部 DOM。当前图谱和列表使用同一 React 元素位置，React 会复用容器并清除 Cytoscape 子节点，随后 Cytoscape 清理时再次移除同一节点，从而抛出异常。

修复后画布容器保持独立且常驻，列表使用另一个 React 容器。切换列表只改变显示状态，不再让 React 接管 Cytoscape 的内部节点；恢复图谱时调用 `resize` 和 `fit` 重新适配画布。

## 验收标准

- 每个现有 AI 请求入口在等待期间显示阶段、进度条和百分比。
- 成功后进度达到 100%，失败时保留原有错误和数据保护行为。
- 人物关系在图谱与列表之间反复切换不会崩溃。
- 点击人物列表条目仍能打开对应证据。
- lint、typecheck、Vitest、production build 和 Playwright 回归通过。
