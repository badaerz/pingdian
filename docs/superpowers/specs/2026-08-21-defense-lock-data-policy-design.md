# 答辩锁定与数据边界设计

## 目标

在不改变现有模块名称和创作流程的前提下，提供一个可重复的答辩运行模式：内置答辩案例保持稳定、外部 AI/生图/云端同步不成为单点故障，同时避免把完整私密作品写入 AI 运行日志。

## 运行模式

- `NEXT_PUBLIC_DEMO_LOCKED=true`：答辩模式。
  - `/api/ai` 和 `/api/assets/generate` 强制走结构化 Demo/本地资产。
  - Supabase 浏览器客户端不创建，项目只使用本地存储。
  - 内置项目 `demo`、`demo-demo_002` 的章节、人物、世界观、蓝图和版本只读。
  - 候选生成、一致性检查、文学分析、知识图谱和训练展示仍可运行；候选不会覆盖正文。
- `NEXT_PUBLIC_DEMO_LOCKED=false`：QA/产品模式。
  - 使用服务端 DeepSeek/ModelScope 和独立 Supabase 测试项目。
  - 内置答辩案例的档案结构仍不可删除；加载时恢复 canonical 的项目、章节、人物、世界观、蓝图、版本和上下文基线。
  - 外部调用失败时仍保留 Demo 降级。

## 数据处理

- 项目正文、人物、世界观和蓝图默认保存在浏览器 `localStorage`。
- 生图 Blob 保存在浏览器 IndexedDB。
- AI 运行同步只保存对象/数组形状、字段名和长度，不保存完整提示词、上传文本、候选正文或模型分析正文。
- 训练记录保留用户主动提交的答案和反馈，用于版本链和成长趋势；设置页清除操作同时清除本地记录并尝试删除远端记录。
- 公共知识库只允许公开/授权/核验来源进入公共检索；私有上传文本为会话级分析，不写入公共知识库。

## 验收

1. 答辩锁定模式下没有 provider API 请求，主案例正文结构不能改变。
2. 新建用户项目仍可创建和编辑，锁定只作用于内置答辩项目。
3. AI 运行云端 row 中不出现完整输入或结果文本。
4. 未开启锁定时，原有实时 API、Supabase 同步和本地降级行为保持不变。
5. 全量测试、类型检查、Lint、生产构建和关键路由 smoke 均通过。
