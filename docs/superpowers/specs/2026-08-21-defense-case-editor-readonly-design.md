# 答辩案例编辑区永久只读设计

## 目标

内置答辩案例 `demo` 与 `demo-demo_002` 的正式作品内容必须永久只读，不依赖 `NEXT_PUBLIC_DEMO_LOCKED`。用户自建项目继续保持完整编辑能力。

## 权限边界

- 永久禁止修改答辩案例的章节标题、章节摘要、正文、人物、世界观、蓝图和版本。
- 永久禁止新增、删除、排序以及切换上述实体的事实锁定状态。
- 允许浏览、导出、文学诊断、IP 实验和 AI 候选生成。
- 允许编辑或丢弃尚未写入作品的 AI 候选，便于答辩演示生成流程。
- 禁止采纳候选、版本回退或其他会把候选内容写回正式案例的操作。
- `NEXT_PUBLIC_DEMO_LOCKED` 继续只控制外部 AI、生图和公开检索等答辩运行行为，不再决定案例内容能否编辑。

## 实现边界

创作台根据 `isDefenseProjectId(activeProjectId)` 统一计算内容只读状态，并传给档案导航、章节字段、正文编辑器、实体编辑器、候选采纳和版本抽屉。状态提供层对答辩案例的受保护字段执行相同校验，拒绝任何绕过界面的写入；候选、分析快照等非正式作品状态仍可更新。

## 验收

1. 在 `NEXT_PUBLIC_DEMO_LOCKED=false` 时，两个答辩案例的章节、正文、人物、世界观和蓝图控件仍为只读。
2. 答辩案例不能新增、删除、排序实体，不能切换事实锁定，不能采纳候选或回退版本。
3. 答辩案例仍能生成、编辑和丢弃候选，并能进入分析、IP 实验和导出流程。
4. 通过直接调用状态更新入口也不能改变答辩案例的受保护字段。
5. 用户自建项目的编辑、候选采纳和版本操作保持可用。
6. 相关组件测试、状态边界测试、类型检查、Lint 和生产构建通过。
