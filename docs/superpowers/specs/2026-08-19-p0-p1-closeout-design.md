# P0/P1 收口设计

## 目标

在不改变离线优先和匿名数据边界的前提下，补齐 PRD P1 的知识库规模、经典文本解构和课堂演示路径，并保持 P0 创作闭环稳定。

## 方案

1. 本地知识目录保留现有 8 部完整条目，增加 12 部轻量结构化条目，总量达到 20 部。远程 `kb_works` 结果与本地目录按 ID 合并，远程字段优先，本地补充条目用于断网和未完成远程导入时的展示。
2. 知识图谱详情侧增加作品解构区域，展示摘要、情节阶段、意象/技法、片段证据、写法解释和训练提示。数据来自现有知识条目的结构化字段，不生成新的长篇受版权保护文本。
3. 训练页增加参考作品与技法目标区域。它只改变课堂演示上下文，不改变用户答案、反馈和 Supabase 记录格式；共享练习和作品仍为本地素材。

## 验收

- 知识检索默认展示 20 部，筛选后结果稳定，远程数据与本地补充可合并，断网仍可用。
- 点击知识作品节点可看到至少一个片段证据、结构阶段、技法解释和训练提示。
- 训练页能选择参考作品，显示其技法目标和解构提示，提交/再次评价流程继续工作。
- P0/P1 既有测试不回归，lint、typecheck、Vitest、build、Playwright 全部通过。
