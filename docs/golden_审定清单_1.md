# golden set 人工审定清单

> 由 `node scripts/golden-review.mjs` 生成。推理由 AI 起草，**必须人审定**才计分。

## 怎么用

1. 逐条看每个 case 下面的结论，只判断一件事：**这条结论，真的是这段文本里的问题吗？**
2. 在每条的 `[ ]` 里打 `x` 表示「成立」，打 `/` 表示「不成立」；不改动的保持 `[ ]`
3. 判完整行 case 后，在 case 末尾的 `审定人：` 后面写你的名字
4. 存盘，然后跑 `node scripts/golden-review.mjs --apply`

**只标 `x` 的会被写进 JSON。** 标 `/` 或留空的，该条不会被记为审定通过，
整个 case 也不会被标为已审定——宁可留白，不要凑数。
